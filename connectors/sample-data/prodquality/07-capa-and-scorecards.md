# CAPA #NS-01 and Supplier Scorecards

## Corrective action — CAPA #NS-01

**CAPA #NS-01** is an open corrective action addressing the NorthStar
cold-performance defect. It is a corrective action for the supplier **NorthStar
Cells Ltd.** and it **quarantines Cell Lot NS-2411**. Planned actions:

1. Quarantine all VC-BAT-20 packs built from lot NS-2411.
2. Require NorthStar to **revert the electrolyte formulation**.
3. **Re-qualify** NorthStar cells at 20°F before issuing any new purchase order.
4. In the interim, revert battery-pack production to **Apex lot AX-2409** (88%
   cold retention).
